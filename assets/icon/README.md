# Іконка гри

`icon.svg` — джерело (монограма «TW» з діркою від кулі в кольорах гри). З нього:

* `icon.ico` — для Windows (16–256 px), вбудовується в `toon-warfare.exe` (`crates/client/build.rs`);
* `icon-16.rgba`, `icon-32.rgba`, `icon-64.rgba` — сирі RGBA-пікселі для іконки вікна;
* `icon-256.png`, `icon-512.png` — для ярликів, сторінки релізу тощо (у збірці для Linux
  лежить як `toon-warfare.png`).

Шрифт — DejaVu Sans Bold (`assets/fonts`).
